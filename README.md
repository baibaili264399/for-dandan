# 你想知道的一切 · 9 格互动页

手机优先的九宫格互动页面。点封面打开 → 点任意一格 → 弹出图片和文字。

## 怎么打开

**方式一（推荐，直接双击也行但要装东西）：** 直接双击 `index.html` 就能看，功能全在。

**方式二（和线上完全一致）：** 在本目录执行

```
python -m http.server 8765
```

然后浏览器打开 http://127.0.0.1:8765/index.html

## 文件都管什么

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `content.js` | **所有文字**、9 张卡片、彩蛋。改文案只动这一个文件 | 你主要改这个 |
| `index.html` | 页面骨架 | 基本不用动 |
| `style.css` | 颜色、圆角、椭圆形状、动画 | 想调外观再动 |
| `script.js` | 交互逻辑 | 不用动 |
| `images/card-1~9.png` | 9 张示例图片，换成你的照片 | 换成 `card-N.jpg` |
| `music/music.mp3` | 放这里就能播背景音乐 | 自己放 |
| `make_placeholders.py` | 生成示例图片的脚本 | 想重新生成时跑 |

## 常用的几个改动

**换文字**：打开 `content.js`，`CARDS` 里每一项就是一张卡片，`title` 是标题，`text` 是正文（数组，一项一段），`hint` 是格子里数字下面那行小字。

**方框选项页**：第 9 格用的是 `layout: 'options'`，点开会先出 4 个方框，点方框才进正文。

```js
{
  num: '关于我',          // 椭圆里的字，写汉字会自动缩小字号
  title: '关于我',
  layout: 'options',
  options: [
    { label: '1', title: '我自己', text: ['第一段', '第二段'], image: '' },
    { label: '2', title: '我对你的感觉', text: ['...'], image: '' },
    { label: '3', title: '第 3 格 · 待填', text: ['...'], image: '' },
    { label: '4', title: '第 4 格 · 待填', text: ['...'], image: '' }
  ]
}
```

- `label` 是方框上那个大字（写数字就是手写数字，写汉字就是小一号的汉字）
- `title` 是方框下面那行小字，留空就不显示
- 不满 4 个也行，写几个就显示几个（会自动排成两列）

**换图片**：把你的照片改名成 `card-1.jpg`（格式随意，jpg/png 都行）放进 `images/`，再把 `content.js` 里对应的 `image: 'images/card-1.png'` 改成 `'images/card-1.jpg'`。

**改颜色**：`style.css` 最上面的 `:root` 里有 `--spot`（椭圆那个红）和 `--paper`（背景色）。

**改完不用刷新**：回到网页点右上角「↻ 重载文案」。

## 交互清单

- 封面信封：点击有开盖动画，然后进九宫格
- 九宫格：鼠标悬停上浮 + 轻微 3D 倾斜，看过的格子标「已看」
- 弹层：图片、标题、正文；底部「上一个 / 下一个」，键盘 ← → 也能翻，Esc 关闭
- 第 9 格「关于我」：点开是先出 4 个方框，点方框进正文，底部「← 返回选项」可以退回来
- 右上角：🎲 随机抽一格、「♪ 音乐」开关
- 右下角爱心：点满 10 下弹彩蛋
- 网址后面加 `#card=3` 可以直接打开第 3 格；加 `#board` 跳过封面
